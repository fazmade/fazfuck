hooks, subroutines and labels are pointer. you give them a name and they point to a line. they all start with a symbol and get added when the counter going over them.
hooks (#) and subroutines (&) are functions after the and skip what's inside their { }
hooks have paramaters in parenthesis, subroutines don't
hooks should end using end() to stop the run, and subroutines with return() to return to the original place
you can put multiple functions before their insides (line with { ) and they will all be defined to run the same line
labels (%) just add their location as a pointer and that's it

[type] = a constant value or variable reference
[type] ref = a variable reference, this should always mean that the variable will get modified by the function
[type] var = a direct reference to a variable, modifies the variable without reading it (and can thus create a new variable without an error)
for bools you can add ! infront of the value to invert it (won't change the value of the variable)
